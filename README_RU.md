# DIABLO_666 MODPACK EU — стартовый проект

Это исходный каркас публичного Windows-установщика с выбором модов, категориями, поиском, панелью превью и выбором каталога World of Tanks EU.

## Текущий статус

**Это не готовый модпак и не готовый релиз.** Каталог содержит демонстрационные записи, а папки пакетов пустые. Кнопка установки намеренно не устанавливает заглушки. Реальные моды подключаются только после:
1. проверки совместимости с конкретной версией WoT EU;
2. проверки правил Wargaming/Fair Play;
3. проверки лицензии и разрешения на распространение;
4. получения настоящих скриншотов для превью;
5. тестирования установки и удаления на чистой копии клиента.

## Запуск из исходников

Требуется Windows 10/11 с Python 3.10+ и Tkinter.

```powershell
python main.py
```

## Сборка EXE

На Windows установите PyInstaller:

```powershell
py -m pip install pyinstaller
py -m PyInstaller --noconfirm --clean --windowed --name "DIABLO_666_MODPACK_EU" --add-data "catalog.json;." --add-data "assets;assets" --add-data "packages;packages" main.py
```

Готовый EXE появится в `dist/DIABLO_666_MODPACK_EU/`. Для публикации можно использовать `--onefile`, но сначала нужно протестировать обновления, ресурсы и работу антивирусов.

## Добавление мода

1. Создайте папку `packages/<module_id>/files/`.
2. Поместите туда только разрешённые к распространению файлы мода, сохранив требуемую структуру.
3. Создайте `packages/<module_id>/TARGET.txt` с относительным путём назначения от корня игры. Не используйте `..` и абсолютные пути.
4. В `catalog.json` после проверки поменяйте `status` на `ready`, заполните версию, автора, источник, лицензию и статус проверки.
5. Положите реальный скриншот PNG в `assets/previews/` и укажите его в `preview`.

**Важно:** `TARGET.txt` и содержимое пакета должны быть проверены разработчиком для конкретной версии клиента. Не публикуйте пакеты с неподтверждённым происхождением.

## Перед публичным релизом

- Добавить корректное удаление модов по manifest, не удаляя пользовательские файлы.
- Реализовать проверку хешей пакетов и подписанные релизы.
- Добавить безопасное обновление каталога с HTTPS и проверкой подписи.
- Добавить проверку конфликтов модов.
- Проверить восстановление из резервной копии.
- Добавить английскую локализацию и лицензионные уведомления.
- Проверить установщик на чистых Windows 10/11 и нескольких версиях WoT EU.
- Не заявлять, что модпак одобрен Wargaming, если такого одобрения нет.

## Лицензирование

Код каркаса можно дорабатывать и распространять. Это не даёт права распространять сторонние моды, их изображения, логотипы или ресурсы. Для каждого стороннего компонента отдельно проверьте лицензию и разрешение автора.


## Формат пакета
См. `packages/PACKAGE_MANIFEST_EXAMPLE.json`. Каждый модуль должен содержать источник, автора, лицензию, явное разрешение на перепубликацию, проверенную версию клиента, SHA-256 и точные относительные пути установки. Пакет без этих данных не допускается к релизу.

## Скриншоты модов в карточках
Для карточек с `preview_url` установщик загружает изображение со страницы каталога источника и сохраняет кэш в `%LOCALAPPDATA%\\DIABLO_666_MODPACK_EU\\preview_cache`. Если сеть недоступна, показывается локальный концепт, и интерфейс явно помечает его как концепт. Pillow входит в build requirements для показа JPG/PNG.
