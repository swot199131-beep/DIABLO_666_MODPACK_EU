# DIABLO 0.4.5 — прицелы и контроль конфликтов

## Better Reticle Size 1.3 — кандидат, установка заблокирована
Источник: https://wotmods.net/world-of-tanks-mods/sight-crosshair/better-reticle-size/
Автор: Jak_Atackka.
Функции: детальная информация о круге сведения, подсказки и удобство выбора 2D/3D стилей.
Важная проверка: карточка каталога сообщает WoT 2.4.1.1, но файл в списке загрузок назван `Jak_Atackka.betterReticleSize_1.3.zip` с описанием 2.4.1.0. Поэтому DIABLO не разрешает импортировать этот архив в 2.4.1.1 до подтверждения версии автором/новым релизом.

## Контроль конфликтов
- Для модов, заменяющих основной прицел, используется группа `primary_reticle`.
- Для модов, заменяющих фон миникарты, используется группа `minimap_background`.
- При выборе конфликтующих компонентов показывается предупреждение.
- Установка блокируется, пока конфликт не устранён.
- Никакие галочки не снимаются автоматически.
