# Конфиденциальность DIABLO_666 MODPACK EU

Текущая Developer Preview не содержит аккаунтной авторизации DIABLO и не должна собирать телеметрию или передавать игровые данные на сервер проекта.

Локально программа может хранить:
- путь к выбранной папке World of Tanks;
- сохранённые профили выбора модов;
- резервные копии файлов, изменённых DIABLO;
- локальные журналы ошибок и установки;
- кэш изображений предпросмотра.

Эти данные хранятся локально в `%LOCALAPPDATA%\\DIABLO_666_MODPACK_EU` при запуске собранной Windows-версии. Пользователь может удалить их вручную после удаления DIABLO, но перед удалением следует сохранить нужные резервные копии.

Программа обращается к источникам модификаций и GitHub только для функций, которые пользователь запускает явно. Автоматический updater пока не активирован.

Перед публичным стабильным релизом политику необходимо пересмотреть и дополнить контактами владельца проекта.
