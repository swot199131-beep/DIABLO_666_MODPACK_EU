# Импорт модов из официального WG Mod Hub

В версии 0.4.2 DIABLO подключает два компонента через локальный импорт пользовательских загрузок.

## GunMarks Reticle 0.2.5 #8
Официальная страница WGMods: https://wgmods.net/7980/
Описание автора: https://gunmarks.app/mod/reticle
Совместимость: WoT 2.4.1.1, build #989.
Возможности: свой прицел в аркадном/снайперском режимах, круг сведения, индикаторы перезарядки и HP, сетка, центр, количество снарядов, дистанция.
Архив содержит мод и OpenWG GameFace 1.2.2. Если GameFace уже присутствует в папке mods клиента, DIABLO не добавит второй экземпляр.

## HD Minimaps
Официальная страница WGMods: https://wgmods.net/8102/
Описание: https://wotmodsplanet.com/mods/minimap-hd/
В каталоге совместимости указан WoT 2.4.1.1; каталог указывает 68 карт, текстуры 2048×2048. В версии/архиве ориентируйтесь на текущую страницу WGMods.
Не совместим с другими модами, заменяющими фон миникарты.

## Как подключить
1. В DIABLO выберите одну из этих карточек.
2. Нажмите «ИМПОРТ WG MOD HUB».
3. Откройте официальную страницу WGMods и скачайте архив самостоятельно.
4. Вернитесь в DIABLO и укажите скачанный ZIP или WOTMOD.
5. Установщик проверит имя ожидаемого файла, ZIP-структуру, пути и SHA-256, затем создаст локальный пакет.
6. Поставьте галочку у мода и нажмите «УСТАНОВИТЬ ВЫБРАННОЕ».

DIABLO не распространяет чужие бинарники и не обходит авторские условия. Локальный импорт — только для файла, который пользователь сам скачал с указанной официальной страницы. В настоящий момент проверка реального запуска в Windows WoT не выполнялась.
