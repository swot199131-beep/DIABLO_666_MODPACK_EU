# DIABLO_666 MODPACK EU 0.6.0 — краткая инструкция

## Что это
Независимый установщик модификаций World of Tanks EU. Не связан с Wargaming. Каталог содержит карточки, внешние источники, компоненты для локального импорта и заблокированные кандидаты. Наличие карточки не означает, что мод уже встроен в DIABLO.

## Сборка EXE
Исходный архив содержит `BUILD_EXE.bat`. На Windows 10/11 x64 с Python 3.12 запустите этот файл. Результат — `dist\\DIABLO_666_MODPACK_EU.exe`. EXE создаётся локально; готовый Windows-бинарник в текущем исходном ZIP не вложен.

## Первый запуск
1. Установите World of Tanks EU и обновите клиент до версии, указанной в карточках (сейчас каталог локального импорта закреплён на 2.4.1.1).
2. Запустите DIABLO.
3. Укажите корневую папку игры, где находится `WorldOfTanks.exe`.
4. Выберите мод в списке и откройте его первоисточник.
5. Для карточек с локальным импортом скачайте архив с сайта автора/WGMods самостоятельно.
6. Нажмите «ИМПОРТ ОФИЦИАЛЬНОГО АРХИВА», выберите ZIP или WOTMOD.
7. Отметьте импортированный компонент галочкой и нажмите «УСТАНОВИТЬ ВЫБРАННОЕ».
8. Игра должна быть закрыта. DIABLO создаёт резервную копию заменяемых файлов.

## Совместимость
- Не ставьте одновременно несколько модов из группы `primary_reticle`.
- Не ставьте одновременно несколько модов из группы `minimap_background`.
- Не используйте архивы для старых версий клиента.
- Заблокированные карточки нельзя импортировать.
- Не устанавливайте моды, раскрывающие скрытую информацию, автоматизирующие стрельбу или иным образом нарушающие Fair Play.

## Удаление
Закройте игру и нажмите «УДАЛИТЬ МОДЫ DIABLO». Удаляются только файлы, зарегистрированные в состоянии DIABLO; резервные копии хранятся в `%LOCALAPPDATA%\\DIABLO_666_MODPACK_EU\\backups`.

## Превью
Карточки с доступными изображениями загружают миниатюру с каталога источника и сохраняют локальный кэш. Если сеть недоступна, показывается концептуальное изображение с явной пометкой «ПРЕВЬЮ: КОНЦЕПТ».

## Версия 0.6.0 — полноценный Setup EXE
В проект добавлен Inno Setup 6. Для сборки установщика Windows x64 запустите `BUILD_EXE.bat` после установки Python 3.12 и Inno Setup 6. Результат: `dist\\installer\\DIABLO_666_MODPACK_EU_Setup_v0.6.0.exe`. Альтернатива — GitHub Actions workflow `Build DIABLO Windows installer`. В текущем ZIP находится исходный проект сборки, а не готовый Windows EXE: сборочная среда здесь Linux.


## Обновление набора модов и удаление старых (версия 0.6.0)
При повторном нажатии «УСТАНОВИТЬ ВЫБРАННОЕ» DIABLO сверяет новый набор с предыдущей установкой. Старые файлы, которые DIABLO установил и которые больше не нужны, удаляются; исходные файлы, существовавшие до DIABLO, восстанавливаются из резервной копии. Общие для нового набора файлы остаются. Файлы Armor ModPack/ручной установки и изменённые сторонние файлы не удаляются. Если другой модпак изменил файл, который нужен новому DIABLO-моду, установка остановится, чтобы не перезаписать его.


## Профили выбора модов (0.6.0)
- Выберите нужные модификации галочками и нажмите «СОХРАНИТЬ ПРОФИЛЬ».
- Чтобы вернуть сохранённый набор, нажмите «ЗАГРУЗИТЬ ПРОФИЛЬ».
- Загрузка профиля только меняет выбор. Перед установкой DIABLO отдельно проверит конфликты, источники и версию клиента.
