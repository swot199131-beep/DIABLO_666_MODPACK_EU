# Settings Profiles 1.0.0

- Официальная карточка WGMods: https://wgmods.net/8107/
- Прямая загрузка с CDN WG: https://modp.wgcdn.co/media/mod_files/gravity.settings_profiles.2.4.1.1.1.0.0.zip
- Автор: Gravity Assist.
- Клиент: WoT 2.4.1.1.
- Статус каталога: Combat ready.
- Возможности: экспорт/импорт настроек в JSON; профили графики, звука, прицелов, горячих клавиш, чувствительности мыши, маркеров и боевой обратной связи.
- DIABLO не перепубликует бинарник: пользователь скачивает ZIP с WGMods и импортирует его локально.
- Перед импортом желательно экспортировать текущие настройки игры в JSON как резервную копию.

## Установка через DIABLO
1. Выбрать Settings Profiles.
2. Нажать «ИМПОРТ WG MOD HUB».
3. Скачать архив с официальной карточки WGMods.
4. Выбрать ZIP в диалоге импорта.
5. После проверки отметить мод и нажать «УСТАНОВИТЬ ВЫБРАННОЕ».

Примечание: имя .wotmod внутри ZIP проверяется по шаблону `*settings_profiles*.wotmod`. Если автор изменит имя файла в новом релизе, шаблон нужно обновить после проверки нового архива.
