# DIABLO_666 MODPACK EU 0.6.1

Исправление ошибки запуска 0.6.0.

## Исправления
- Добавлены обработчики `save_profile()` и `load_profile()`, которые уже вызывались кнопками интерфейса.
- Профили сохраняются в пользовательской папке приложения `profiles` в формате JSON.
- При загрузке проверяются версия схемы, уникальность и наличие ID модов в текущем каталоге.
- Загрузка профиля только меняет выбранные галочки; установка модов выполняется отдельно после явного нажатия пользователем.

## Проверки
- Проверка синтаксиса Python.
- Unit-тесты проекта.
- Проверка сборки Windows выполняется GitHub Actions.

Сторонние бинарные файлы модов в установщик не включены. Сборка не является подтверждением совместимости всех модов с текущей версией игры.
