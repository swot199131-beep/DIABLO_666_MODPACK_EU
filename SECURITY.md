# Security policy

Сообщайте об уязвимостях приватно владельцу репозитория, не публикуйте рабочие эксплойты и пользовательские данные в открытых issues.

DIABLO должен:
- принимать только HTTPS-источники;
- проверять SHA-256 и manifest до установки;
- запрещать traversal/absolute paths;
- менять только файлы, зарегистрированные собственным состоянием;
- не удалять файлы, изменённые другим инструментом;
- сохранять резервные копии и выполнять откат транзакции.

Публичный контакт security пока не назначен. До назначения владельца репозитория не отправляйте конфиденциальные отчёты в публичные issues.
