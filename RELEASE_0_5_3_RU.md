# DIABLO_666 MODPACK EU 0.6.0 — очистка предыдущего набора модов

## Новое поведение кнопки «УСТАНОВИТЬ ВЫБРАННОЕ»
При повторной установке программа сравнивает ранее зарегистрированные DIABLO файлы с новым выбранным набором:
- старые DIABLO-файлы, которые больше не нужны, удаляются;
- если до DIABLO на этом месте был файл, он восстанавливается из резервной копии;
- файлы, общие для нескольких выбранных компонентов, остаются;
- файлы, изменённые пользователем или другим модпаком, не удаляются;
- если изменённый сторонним инструментом файл совпадает с назначением нового мода, установка останавливается, чтобы не перезаписать чужую модификацию;
- изменения выполняются транзакционно: при ошибке файлы и состояние возвращаются к состоянию до установки.

## Безопасность
- Чужие файлы, не зарегистрированные в состоянии DIABLO, не сканируются для удаления.
- DIABLO не удаляет моды Armor ModPack или ручные установки, если они не были установлены/зарегистрированы самим DIABLO.
- При удалении старого набора пользовательские конфиги не затрагиваются, если они не являются файлами, которыми DIABLO владеет по своему manifest.
- Резервные копии исходных файлов сохраняются в `%LOCALAPPDATA%\\DIABLO_666_MODPACK_EU\\backups`.
