# Подключённый сторонний мод: 14th_ua's MoE Calculator

## Что подключено
- Версия: v9.0.0
- Целевой клиент: World of Tanks EU 2.4.1.1
- Автор: 14th_ua
- Репозиторий: https://github.com/drizzer14/moe-calculator
- Лицензия/условия: LICENSE.md в репозитории разрешает бесплатное распространение и включение в модпаки при сохранении авторства и ссылки на исходный репозиторий.
- Релиз закреплён: https://github.com/drizzer14/moe-calculator/releases/tag/v9.0.0

## Как работает подключение
При выборе мода установщик:
1. Проверяет клиент 2.4.1.1.
2. Проверяет наличие OpenWG GameFace 1.2.2+ в `mods/2.4.1.1`.
3. Если зависимости нет, открывает страницу официальных релизов GameFace и не продолжает установку.
4. Получает метаданные закреплённого GitHub Release v9.0.0.
5. Проверяет, что релиз не draft/prerelease и в описании подтверждён клиент 2.4.1.1.
6. Загружает только `.wotmod` MoE Calculator, не Setup.exe и не сторонние зависимости.
7. Сверяет SHA-256 с digest GitHub, если он опубликован; в любом случае вычисляет локальный SHA-256.
8. Проверяет ZIP-структуру и пути внутри архива.
9. Устанавливает в `mods/2.4.1.1/` с резервным копированием по общему механизму DIABLO.

## Обязательные условия лицензии
- Мод остаётся бесплатным: нельзя продавать, закрывать платным доступом или включать в платный/premium пакет.
- В релизе DIABLO необходимо указывать автора 14th_ua и ссылку https://github.com/drizzer14/moe-calculator.
- Лицензия MoE Calculator не распространяется на OpenWG GameFace. GameFace не копируется и не распространяется DIABLO; пользователь устанавливает её из источника авторов.
- Aslain ModMenu упоминается автором как хост настроек, но README говорит, что без него сам мод всё равно работает. Поэтому он не считается обязательной зависимостью DIABLO.

## Ограничения тестирования
Сборка проверена статически. Загрузка release asset и запуск WoT не выполнялись в текущей среде; финальную работоспособность нужно подтвердить на Windows с чистым WoT EU 2.4.1.1.
