# Прицелы: статус совместимости для 2.4.1.1

## Better Reticle Size 1.3
- Официальная страница: https://wgmods.net/6349/
- Карточка: https://wotmodsplanet.com/mods/better-reticle-size/
- Агрегатор показывает Combat ready, WoT 2.4.1.1, v1.3.
- Однако проверенная прямая ссылка CDN всё ещё ведёт на архив v1.2.5 и отвечает 404.
- DIABLO оставляет карточку заблокированной, пока не будет подтверждён корректный файл.

## Reticle Size Limit Remover
- Исходный код: https://github.com/Pruszko/ReticleSizeLimitRemover
- Мод снимает минимальный размер прицела.
- Отдельный актуальный бинарник для WoT EU 2.4.1.1 не подтверждён.
- Старые архивы 2.2.1.0 и ниже не устанавливать.
- Карточка кандидата заблокирована.

## Доступный текущий вариант
Improved Standard Sight 1.3.0 (WGMods 8117) доступен отдельно и помечен Combat ready для 2.4.1.1. Используйте только один мод из группы замены основного прицела одновременно.
