## Fair Play: обязательные исключения
DIABLO не должен включать моды, которые:
- раскрывают позиции противника или оставляют метки вне штатной видимости;
- рассчитывают позиции артиллерии по трассерам;
- показывают таймер перезарядки противника;
- дают расширенный авто-aim / автоматический выбор слабых зон;
- автоматизируют стрельбу, отпускание/блокировку выстрела или макросы для оптимизации огня;
- изменяют игровые физические параметры или дают информацию за пределами штатных игровых данных.
Перед каждым публичным релизом перечень сверяется с официальной Fair Play Policy.

## Ограничения 0.6.0
- Проект установщика и CI готовы к сборке, но настоящий Windows Setup EXE не создан в текущей Linux-среде.
- Не задан официальный GitHub repository owner/name, поэтому автообновление приложения не включается до публикации репозитория.
- Большинство карточек каталога остаются внешними ссылками или концептами, не установочными пакетами.
- Не выполнена полная проверка модов в настоящем клиенте WoT EU.
- Не подписанный сертификатом установщик может показывать SmartScreen warning.

## Сборка
1. Windows 10/11 x64, Python 3.12 x64, Inno Setup 6.
2. Распаковать проект.
3. Запустить `BUILD_EXE.bat`.
4. Setup EXE появится в `dist\\installer`.

Альтернатива — GitHub Actions workflow `Build DIABLO Windows installer` после публикации репозитория.


## Что требуется от владельца проекта для финального публичного релиза
- Создать GitHub repository и загрузить туда этот проект (workflow уже лежит в `.github/workflows`).
- Запустить Actions → Build DIABLO Windows installer → Run workflow; скачать артефакт Setup EXE.
- Проверить Setup EXE на чистой Windows 10/11 и в WoT EU.
- Для встроенного updater указать URL публичного репозитория в update configuration и включить проверку подписи/хэша скачиваемого обновления.
- Для Authenticode signing добавить собственный сертификат в GitHub Actions secrets.
Без GitHub repository и сертификата нельзя честно опубликовать саморасширяющийся updater или подписанный EXE от имени проекта.
