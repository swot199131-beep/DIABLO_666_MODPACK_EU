# Правила вклада

- Не добавлять модификации без первоисточника, автора, версии, лицензии и проверки совместимости.
- Не включать запрещённые Fair Play функции.
- Не добавлять сторонние бинарники в исходный репозиторий без письменного разрешения на распространение.
- Любой импорт должен иметь manifest с SHA-256, безопасными путями и точной версией клиента.
- Новые функции установщика покрывать unit-тестами.
- Изменения файлов игры должны иметь резервное копирование и безопасный откат.
- Не публиковать пользовательские логи, игровые пути, токены, ключи или сертификаты.
